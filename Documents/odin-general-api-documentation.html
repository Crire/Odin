Odin General API

A General API e a API principal do Odin. Ela atende mobile e dashboard web, centralizando autenticacao, usuarios, dispositivos, grupos, kanban, tarefas, notificacoes agendadas, outbox e eventos em tempo real.

Stack

  • Kotlin 2.4, Java 21 e Spring Boot 4.1.
  • PostgreSQL como banco canonico.
  • Redis para cache, locks, throttle e idempotencia auxiliar.
  • RabbitMQ para eventos de notificacao.
  • Flyway para migrations.
  • Spring Security com JWT proprio.
  • Spring WebSocket/STOMP para tempo real.
  • Springdoc OpenAPI para documentacao interativa.

Responsabilidades

  • Receber requisicoes do mobile e dashboard web.
  • Validar autenticacao e autorizacao.
  • Aplicar RBAC por grupo: ADMIN, EDITOR, MEMBER e VIEWER.
  • Gerenciar dispositivos e push tokens.
  • Gerenciar grupos, membros, boards, colunas e tasks/cards.
  • Validar movimentacao de cards no backend.
  • Criar notification_jobs e outbox_events.
  • Publicar eventos para o worker Go por RabbitMQ quando disponivel.
  • Emitir eventos em tempo real por WebSocket/STOMP.

Fluxo de notificacoes

  1. A API recebe uma acao, como criar card ou atribuir responsavel.
  2. A API valida regras e permissoes.
  3. A API salva task/card no PostgreSQL.
  4. A API cria registros em notification_jobs com idempotency_key.
  5. A API cria outbox_events e tenta publicar em RabbitMQ.
  6. O worker Go processa os jobs vencidos e envia push.
